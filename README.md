# 🍛 Aishwarya Restaurant & Menu Management System

A modern, lightweight web application for managing restaurant menus and real-time pricing with a FastAPI backend and Supabase database integration.

## 🚀 Features
* **Dynamic Menu & Store Management:** Real-time updates via admin panel.
* **FastAPI Backend:** High-performance asynchronous Python backend.
* **Supabase Integration:** Secure PostgreSQL database storage.
* **Responsive Frontend:** Clean and interactive user interface deployed seamlessly.

## 🛠️ Tech Stack
* **Backend:** Python, FastAPI, Uvicorn, SQLAlchemy, Psycopg2
* **Database:** Supabase (PostgreSQL)
* **Frontend:** HTML5, CSS3, JavaScript
* **Deployment:** Vercel
